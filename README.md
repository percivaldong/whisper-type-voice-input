# whisper-type（语音输入）

本地语音转文字工具。按住右 Ctrl 说话，松开自动转写为文字并粘贴到光标位置。完全离线运行，数据不出设备。

---

## 启动方式

双击 **`启动.bat`**，首次运行会自动下载模型到 `models/` 目录。

如果按右 Ctrl 没反应，右键 `启动.bat` → **以管理员身份运行**（麦克风和键盘模拟需要系统权限）。

---

## 操作方式

| 操作 | 效果 |
|------|------|
| **按住右 Ctrl** | 开始录音 |
| **松开右 Ctrl** | 自动转写并粘贴到光标位置 |
| **Ctrl+C** | 退出程序 |

终端状态提示：

```
[whisper-type] ● 录音中...        ← 正在听
[whisper-type] ○ 转写中...        ← 正在处理
[whisper-type] → 识别的文字内容    ← 成功，已粘贴
[whisper-type] (未识别到语音)      ← 没听到有效语音
```

## 技术参数

| 配置项 | 当前值 | 说明 |
|--------|--------|------|
| 模型 | small（~1.5GB） | 中文 + 英文混说，精度与速度均衡 |
| 触发键 | 右 Ctrl | 可在 `speak.py` 中修改 `TRIGGER_KEY` |
| 识别语言 | zh | 可在 `speak.py` 中修改 `LANGUAGE` |
| 采样率 | 16000 Hz | 语音识别标准采样率 |
| 推理设备 | CPU / int8 量化 | 无需 GPU，普通电脑即可 |

### 可选模型

在 `speak.py` 中修改 `MODEL_SIZE` 即可切换：

| 值 | 大小 | 速度 | 精度 |
|----|------|------|------|
| tiny | ~150MB | 最快 | 一般 |
| base | ~300MB | 快 | 尚可 |
| **small** ← 当前 | **~460MB** | **中等** | **好** |
| medium | ~1.5GB | 慢 | 很好 |
| large-v3 | ~3GB | 很慢 | 最好 |

## 隐私说明

- **录音不会保存**：音频写入临时文件 → Whisper 转写 → 立即删除，磁盘上不留痕迹
- **文本不会记录**：转写结果仅在内存中短暂停留，粘贴到剪贴板后消失，不写日志不存文件
- **全程离线**：依赖 faster-whisper（本地引擎），无需联网，语音数据不发送到任何服务器

## 适用范围

系统级全局语音输入，**不限于 Claude Code 或 VSCode**。光标在哪就输入到哪——终端、浏览器、微信、Word 等全部可用。

## 常见问题

**Q: 双击启动.bat 窗口闪退？**  
A: 右键 `启动.bat` → 以管理员身份运行。

**Q: 按住右 Ctrl 没反应？**  
A: 以管理员身份运行，或检查是否有其他软件占用了右 Ctrl 快捷键。

**Q: 模型下载速度慢？**  
A: 模型从 HuggingFace 下载，首次约需 5-10 分钟（取决于网络）。设置环境变量 `HF_ENDPOINT=https://hf-mirror.com` 可使用国内镜像加速。

**Q: 想换触发键？**  
A: 编辑 `speak.py`，修改 `TRIGGER_KEY`。常见可选值：`Key.ctrl_r`（右 Ctrl）、`Key.caps_lock`（大写锁定）、`Key.f9`（F9 键）。
